OpenMontage template update request

Goal:
Promote the current proof-of-concept into a cleaner default review template for talking-head clips from long-form video.

Decision:
Adopt square subtitled output as the default reviewable proof format.
Do not use the large hook overlay as the default.
Subtitles should carry the hook naturally in most cases.

Reference preference derived from current proofs:
- Preferred direction: square + subtitled
- Less preferred direction: square + subtitled + large hook overlay
- Reason: the large hook treatment consumes too much frame real estate and competes with both the speaker and the subtitles

Template-level changes requested:

1. Output format
- Set default review output to 1080x1080 square
- Preserve current talking-head framing behavior unless face-safe recentering is needed

2. Subtitle default
- Burn subtitles by default for review exports
- Keep current subtitle styling unless noted below
- Prioritize readability on mobile and clean review visibility

3. Subtitle vertical placement
- Move subtitle block from center/mid-frame to lower-third
- Target subtitle anchor around 75% to 78% from top of frame
- Maintain bottom safe margin so subtitles do not collide with platform UI
- Goal: keep subtitles off the speaker’s mouth/face zone for talking-head clips

4. Hook overlay behavior
- Disable large hook overlay by default on square subtitled talking-head exports
- If hook text is enabled, use a minimal top-bar treatment only
- Do not allow hook text to occupy central viewing area
- Spoken opening + subtitles should serve as the default hook mechanism

5. Composition rules
- Priority order for square talking-head clips:
  1) face visibility
  2) subtitle readability
  3) clean negative space
  4) optional hook label
- Avoid stacking large hook text and centered subtitles on top of the subject

6. Re-centering / framing logic
- Review whether current centering is clip-specific or globally applied
- If needed, use talking-head safe framing so eyes/face remain visually prioritized after square crop
- Subtitle position should be independent of crop center so the text can stay lower even when subject framing changes

7. Export request
- Produce 1 updated review export from an existing talking-head proof clip using:
  - 1080x1080 square
  - burned subtitles
  - subtitle Y-position lowered to lower-third
  - no large hook overlay
- This export becomes the new baseline review template candidate

Acceptance criteria:
- Speaker face is not materially blocked by subtitle lines
- Subtitle readability remains strong on mobile
- Frame feels less crowded than the current hook-overlay version
- Result is suitable as the default reviewable proof asset template

else:
