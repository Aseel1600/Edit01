# MILO: THE CAT WHO WANTED SPACE

A vertical viral short built with the Remotion runtime in this repo.

| | |
|---|---|
| **Composition** | `CatSpace` (`remotion-composer/src/CatSpace.tsx`) |
| **Entry point** | `remotion-composer/src/catSpaceIndex.tsx` (isolated — see note below) |
| **Resolution** | 1080 × 1920 (9:16) |
| **Frame rate** | 30 fps |
| **Duration** | 1650 frames = **55.000 s** exactly |
| **Keyframes** | **30 shots** × 55 frames = 1.833 s per shot |
| **Output** | `output/cat-to-space/milo-space-55s.mp4` |

## Structure

Three-act viral beat map, cut on a strict 1.833 s grid so every caption lands
on a hard cut:

| Act | Shots | Time | Beat |
|-----|-------|------|------|
| Hook | 01–05 | 0.0–9.2 s | Cold-open claim, meet Milo, the doubt, the "watch me" |
| Try / Fail | 06–12 | 9.2–22.0 s | Cardboard rocket, 47 crashes, the low point |
| Train | 13–18 | 22.0–33.0 s | The fence, the montage, the real suit |
| Launch | 19–24 | 33.0–44.0 s | Gantry, hatch, countdown, liftoff |
| Payoff | 25–30 | 44.0–55.0 s | Silence, orbit, the tear, the can opener, home |

## Audio

Three voices plus a procedural score. Cues are hand-placed against the measured
length of each clip so nothing overlaps.

| Cue | Voice | Starts | Line |
|-----|-------|--------|------|
| `vo1` | Narrator | 0.00 s | This cat is going to space. Really. His name is Milo. They said cats don't fly. Milo said: watch me. |
| `vo2` | Narrator | 10.50 s | He drew the plans. He built the rocket. Launch attempt one was not space. Neither were the next forty-six. |
| `vo3` | Narrator | 19.60 s | Then he found the fence. So he trained. He ran. He studied. He held on. They built him a suit his size. |

`score.wav` is generated by `scripts/make_cat_space_score.py` — a
stdlib-only synth (Am–F–C–G pad, sub, heartbeat kick from the training montage,
noise riser through the countdown, boom on liftoff, shimmer in orbit, plus a
soft whoosh on all 29 cuts). It auto-ducks to 0.17 gain under every voice cue.

## Motion / grade

- Ken Burns on every frame, alternating push-in / pull-out (1.06 ↔ 1.19) with a
  per-shot pan bias.
- 7-frame cross-dissolve between shots.
- Camera shake on shots 10, 17, 22, 23, 24.
- White flash on the impact beats (05, 10, 22, 23, 24, 29).
- Top/bottom gradient falloff + vignette so captions always read.
- Animated film grain at 6 % overlay.
- Top progress bar (cyan → amber) — retention device.
- Captions: Anton, 88 px (108 px on the hook), 16-point stacked-shadow outline,
  spring pop-in, 300 px bottom padding to clear platform UI.

## Rendering

```bash
scripts/render_cat_space.sh
```

Notes on this sandbox:

- **Isolated entry point.** `src/index.tsx` registers every composition in the
  repo, and several of them call `@remotion/google-fonts` `loadFont()` at import
  time. In a network-restricted environment those requests fail and the render
  aborts before it starts. `src/catSpaceIndex.tsx` registers only `CatSpace`.
- **Vendored font.** Anton is taken from the `@fontsource/anton` npm package and
  inlined as base64 in `src/antonFont.ts`, installed via a `@font-face` rule at
  module scope. No Google Fonts request is made. (An async `FontFace` load
  behind `delayRender()` — the documented Remotion pattern — does *not* work
  here: the handle outlives the render loop and the render aborts at the
  timeout, ~180 frames in.)
- **Browser.** Remotion's Chrome Headless Shell CDN (`remotion.media`) is not
  reachable here. The render script falls back to a Chromium binary unpacked
  from the `@sparticuz/chromium` npm package, with its bundled shared libraries
  on `LD_LIBRARY_PATH`, passed via `--browser-executable`.

## Assets

All generated media lives under `remotion-composer/public/cat-space/`, which is
covered by the repo's `remotion-composer/public/*` ignore rule (media is
regenerable and never committed):

- `shot01.png` … `shot30.png` — 30 keyframes, generated from a single character
  reference sheet (`projects/cat-to-space/ref/milo_ref.png`) so Milo stays
  consistent: orange tabby, white chest, torn left ear, red knitted scarf.
- `vo1–5`, `mc1–2`, `milo1–2` `.mp3` — narration (3 distinct voices).
- `score.wav` — procedural score.
